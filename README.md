# Parts&Stock

Parts&Stock is an open-source inventory management system written in C#, born from need within my electronics repair and reselling business. 
The goal is to build a fast, intuitive, granular system capable of tracking everything from indivduals components to complete systems. 

## Current Status

Parts&Stock is currently in an early CLI phase and in active development. 
This is the dev branch. Currently this is the only version of the program,
whenever v1.0.0 launches it will be on a different branch and this one 
will be a development version. 

Current features include: 
- Adding inventory items
- Item lookup
- JSON based data storage

### Roadmap

Planned features include:
- SQLite database backend
- Barcode/QR code generation and support
- Advanced Searching and Filtering
- Inventory Statistics
- Sourcing/Supplier Management
- GUI
- Data importing/exporting
